\section{Enuma Elish as a Relational-Genesis Formalism}
\label{sec:enuma-relational}

This section records a source-bound formalization of selected creation events
in \emph{Enuma Elish}.  The result is typed as \textbf{FORMALIZATION}; no
mythic entity is thereby identified with a modern physical field, particle, or
cosmological observable.

\subsection{Narrative state}

Let
\[
S_k=(V_k,R_k,N_k,D_k,F_k,B_k,T_k),
\]
where $V$ is an entity set, $R$ a set of typed relations, $N$ explicit naming
acts, $D$ destiny assignments, $F$ functional assignments, $B$ separation
boundaries, and $T$ an append-only provenance trace.

The operator record is
\[
O_i=(\mathrm{id},\mathrm{kind},\mathrm{inputs},
\mathrm{outputs},\mathrm{source}).
\]
An executable operator without a source identifier is rejected.

\subsection{Scoped relational zero}

For the primordial-carrier set
\[
P=\{\mathrm{Apsu},\mathrm{Tiamat}\},
\]
define
\[
Z_R(S)=1
\]
iff
\[
V(S)\subseteq P,
\qquad
N(S)=D(S)=F(S)=B(S)=\varnothing,
\]
and all admitted relation endpoints lie in $P$.

The condition does not require $R(S)=\varnothing$.  The Tablet~I witness
supports the primitive relation
\[
\mathrm{Apsu}
\xrightarrow{\mathrm{MINGLED\_WITH}}
\mathrm{Tiamat}.
\]
Hence relational zero is not formal nothingness:
\[
\boxed{\text{relational zero}\neq\text{empty state}.}
\]

\subsection{Operators}

The current algebra contains
\[
\rho\quad\text{(relation)},\qquad
\delta\quad\text{(generation/differentiation)},\qquad
\nu\quad\text{(naming)},
\]
\[
\sigma\quad\text{(destiny assignment)},\qquad
\beta\quad\text{(separation/boundary)},\qquad
\phi\quad\text{(function assignment)}.
\]

Tablet~I.7--10 yields the first decisive transition:
\[
S_0\xrightarrow{\delta}S_1\xrightarrow{\nu}S_2,
\qquad
Z_R(S_0)=1,
\qquad
Z_R(S_1)=0.
\]
The distinction is structural rather than numerical: generated entities and
explicit naming appear where the preceding state explicitly lacks them.

The preserved opening then gives an ordered differentiation through Anshar,
Kishar, Anu, and Nudimmud.  The relation is textual precedence, not by itself
a physical time coordinate.

The Tablet~IV witness supplies the separation operator
\[
\beta(\mathrm{Tiamat}\rightarrow U,L),
\]
with one part established as sky.  In the formal model the invariant is the
introduction of two regions and a boundary:
\[
1\longrightarrow2.
\]

A Tablet~VI witness supplies a later class/function transition for humanity,
represented schematically as
\[
\delta(\varnothing\rightarrow H)
\quad\text{followed by}\quad
\phi(H).
\]

Thus the selected source projection has the generative form
\[
\boxed{
Z_R
\longrightarrow
\delta
\longrightarrow
\nu
\longrightarrow
\beta
\longrightarrow
\phi
}
\]
with omitted narrative material retained as omitted rather than silently
invented.

\subsection{Memory law}

Each accepted transition extends, but never rewrites, the provenance trace:
\[
T_{k+1}
=
T_k\Vert
\langle
\mathrm{id}(O_k),
\mathrm{kind}(O_k),
\mathrm{source}(O_k)
\rangle.
\]
At this representation layer, memory is therefore preserved relation-change
history.  This is a mathematical model of narrative memory, not an empirical
claim that physical memory must instantiate the same data structure.

\subsection{Epistemic boundary}

The formal claim is that \emph{Enuma Elish} admits a compact generative
grammar spanning pre-differentiation, entity generation, explicit identity,
boundary formation, and functional allocation.  The stronger equation
\[
G_{\mathrm{Enuma}}
\cong
G_{\mathrm{physical\ reality}}
\]
is a physical hypothesis and requires independent empirical evidence,
preregistered mappings, and null-model comparison.

The previous project archive mentions a 143-statement Enuma formalization.
The standalone 143-statement corpus was not recovered in the present
provenance pass, so no 143/143 verification is claimed here.
